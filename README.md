Trivia Game

An interactive quiz application designed to test knowledge across various domains with a structured difficulty system.

Project Overview
Trivia Game is a logic-based challenge where users answer multiple-choice questions. The project is focused on clean state management and organized data structures for categorized content.

 Key Features
 4 Diverse Categories:
  Programming:** Technical questions for developers.
  Traffic Rules: Essential knowledge for road safety.
  History: Key events and historical acts.
  Geography: World maps, capitals, and landmarks.
 3 Difficulty Levels: Choose between Easy, Medium, and Hard to match your expertise.
Structured Gameplay: Each session consists of 10 unique questions with 4 possible answers.

Tech Stack
Language: HTML, CSS, JavaScript]
Architecture: Modular data-driven design.

How to Play
1. Clone the repository.
2. Run the main executable/script.
3. Select your category and challenge level.
4. Aim for 10/10.
